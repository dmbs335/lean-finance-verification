# Lean Finance Verification

A Lean 4 based formal research framework for financial systems.

## Goals

- Proof-Carrying Backtests
- Point-in-time data correctness
- Formal market models
- Game-theoretic equilibrium verification
- Machine-checkable research certificates

## Structure

```
LeanFinance/
  GameTheory/
  Market/
  Backtest/
  Inference/
  Certificate/
```

The principle is separating empirical estimation from formally verified claims.
