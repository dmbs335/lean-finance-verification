# Proof-Carrying Backtest Trust Boundary

A certificate proves only the propositions encoded in its Lean type.

## Inside the current trusted claim

- Each listed dataset was publicly available by the declared decision time.
- Each listed dataset has a non-empty content hash.
- The selected parameter hash occurs in the disclosed search ledger.
- Feature lineage was generated by the declared decision time and names its input hashes.
- The experiment records code, data, parameter, and environment versions.

## Outside the current trusted claim

- Future profitability or economic significance.
- Truthfulness of externally supplied timestamps and hashes.
- Completeness of the disclosed hypothesis-search ledger.
- Absence of omitted datasets, experiments, or strategy variants.
- Correctness of statistical estimators, transaction-cost models, and market data vendors.
- Correctness of the Lean compiler, kernel, operating system, and cryptographic hash implementation.

## Intended verification chain

```text
external artifacts
  -> hash and timestamp attestations
  -> certificate compiler
  -> Lean certificate object
  -> kernel-checked theorem
```

The research program should progressively narrow the external trust base by adding signed manifests, point-in-time archives, deterministic adapters, and independently reproducible builds.
